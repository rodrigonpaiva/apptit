## Local demonstration

```sh
npm run local:env
npm run dev
```

Open http://127.0.0.1:3000/login. Individual synthetic login/password pairs are in the private ignored `.local/fixture-credentials.json`; they are not logged or embedded in the UI. Sign in as Chef A, open workspace and verify Restaurant A/name/role. Use logout/change user, then Cook A. A separate Chef B account supports denied cross-site requests in smoke. The multisite fixture can select either explicitly permitted site.
