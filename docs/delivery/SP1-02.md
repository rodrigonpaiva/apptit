- `npm run db:seed` twice: idempotent synthetic runtime markers; no login/stock feature enabled.
- `npm run dev`: actual one-command Docker/migration/seed/startup verified, all four runtimes running and TypeScript watcher reported zero errors. Ctrl+C terminated the supervised runtime/watch groups with exit code 0. Nx analytics is explicitly disabled to avoid an interactive first-run prompt.

These checks demonstrate the scaffold, not business authorization, stock atomicity, offline durability or restaurant readiness.
