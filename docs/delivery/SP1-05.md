## Verification

- `npm run check`: Prisma, lint/boundaries, seven-project types/build, design contracts and 17 existing unit/security/configuration/policy tests passed.
- `npm run db:migrate`: additive catalogue table applied. Repeated `db:seed` (including dev startup) succeeded.
- `npm run test:integration`: 12 real PostgreSQL tests — six quantity/schema-chain, two catalogue and four sessions. Catalogue tests cover compound scope isolation, missing capability, leading-zero/null codes, empty results and deterministic 100-row bound. Schema-chain test includes the new migration and preservation of an existing runtime marker.
- `npm run smoke`: HTTP foundation and catalogue checks passed, including authorized cook reads, distinct site products, unauthenticated/internal service-only denial, forged role/cross-site denial, revocation and dependency outage.
- Real Chromium from the existing local Playwright cache: login → private list → textual barcode search → no-result recovery → logout passed. Phone/tablet captures were inspected. Programmatically dispatched blur/focus events hid products and caused a fresh load. Loading used a delayed real response; empty/error states used controlled browser response interception, then retry returned to real data. No camera permission, JavaScript page errors or horizontal overflow were observed. This is browser emulation, not a physical phone/tablet test or full accessibility audit.

Local ignored captures: `.local/qa-sp1-05/phone-390.png`, `tablet-768.png`, `empty.png`, `error.png`. The default browser connector lacked Chrome; QA used the already-installed Chromium directly. No browser installation or dependency change was required.
