## Delivered scope

- Runtime types for receipt/product/presentation/batch/line identity, draft save, versioned confirmation intent, future immutable receipt ledger entries and separate draft/stock outcome ports.
- Pure checked whole-pack conversion preview, exact four-bucket reconciliation and explicit incomplete/unknown handling.
- Deterministic parsed command intent/scoped operation key comparison; durable registry, concurrency and uncertain-outcome behavior specified before posting.
- Evidence declaration/ownership/links and pending/available/failed shapes; pure explicit size/type-policy validation, separate future metadata/private-byte ports.
- Four executable synthetic JSON examples plus compile-only outcome/readonly-state proofs included in contracts:check.
